2. Recommended Technology Stack

Layer Technology Purpose & Rationale
Frontend Next.js 14 / React 18, TypeScript, Tailwind CSS High performance responsive enterprise UI, dynamic data tables, interactive cost charts.
Backend API FastAPI (Python 3.11+) High-speed async API service, native typing, AI/ML integrations, and PDF report builders.
Database PostgreSQL / SQLite with SQLAlchemy & Alembic Relational integrity, JSONB support for dynamic line-items, quotation revisions, and audit trails.
AI Engine Gemini AI Integration (Structured JSON Mode) Automated GFC document parsing, bottom-up MLEO cost modeling, and negotiation intelligence.
PDF Generation ReportLab / WeasyPrint Corporate-grade Work Order & Purchase Order PDF generation with digital stamps.
Auth & Security JWT + Role-Based Access Control (RBAC) Granular permissions across Requester, Buyer, Estimator, Approver, Admin, and Vendor.

4. Acceptance Criteria Checklist (Phase 1 Baseline)

  • ✓ PR Creation: Submit PR without mandatory budget upload or budget checks.
  • ✓ Tri-Route BOQ: GFC → BOQ (AI-assisted), Standard Templates, and Excel Upload.
  • ✓ Full Auditability: PR approval, buyer assignment, price revisions, and approvals logged.
  • ✓ Commercial Check: Normalized 4-way comparison across Rate Card, Vendor Quotes, Benchmarks, and Standards.
  • ✓ AI Cost Intelligence: Material, Labour, Equipment, Overheads (MLEO) break-up with human-in-the-loop override.
  • ✓ Vendor Negotiation Hub: Logs counter-offers, revised quotes, target prices, and justifications.
  • ✓ PPO & Work Order / PO: Digital PPO approval triggers Work Order / PO generation with PDF download.
  • ✓ Strict Scope Guard: Excludes project budget uploads, shortfall requests, billing checks, and execution certification.
